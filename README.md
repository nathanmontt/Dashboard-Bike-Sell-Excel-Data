<h1 id="sobre-o-projeto">Sobre o Projeto</h1>

O dashboard em questão tem o intuito de introduzir a aplicação de meus conhecimentos sobre Análise de Dados em <strong>Excel</strong>. O projeto conta com um dataset vindo de um repositório do github do canal [Alex The Analyst](https://www.youtube.com/@AlexTheAnalyst/featured) apresentado no vídeo [Full Project in Excel | Excel Tutorials for Beginners](https://www.youtube.com/watch?v=opJgMj1IUrc).


<h3 id="tecnologias-usadas">Tecnologias Usadas</h3>

Foi usado apenas a ferramenta de planilhas <strong>Microsoft Excel</strong>
